# ⚛️ React Component & Props Mini-Project

Welcome to the **Component & Props** mini-project! This is a beginner-friendly React application .

If you are just starting to learn React, this project is perfect for you! It focuses on the core building blocks of React: **Components** and how to pass data between them using **Props**.

---

## 🚀 What Will You Learn?
- **Components:** How to break a UI down into reusable, independent pieces (e.g., UI Cards).
- **Props (Properties):** How to pass custom data (like titles, images, or descriptions) from a parent component down to a child component.
- **Vite Setup:** Experience an incredibly fast modern React development server.

## 🛠️ Prerequisites
Before running this project, make sure you have [Node.js](https://nodejs.org/) installed on your computer.

## 🏃‍♂️ How to Run the Project Locally

Follow these simple steps to get the project running on your own machine:

1. **Open your terminal** and make sure you are in the project folder (`component_props_project`).
2. **Install the dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
4. **Open in Browser:** Copy the local URL (usually `http://localhost:5173/`) from your terminal and paste it into your web browser.

---

## 📂 Project Structure Overview
- `src/App.jsx` — The main parent component where our app starts.
- `src/component/cards.jsx` — A custom reusable child component that accepts props!

## 💡 Quick Tip for Beginners!
Check out the `src/component/cards.jsx` file to see how variables are passed around inside `{ curly braces }`. Try changing the text passed to the card component inside `src/App.jsx` and see the browser update instantly!
